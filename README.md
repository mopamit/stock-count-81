# ספירת המלאי

משחק של פריזמה (רשת אמית) לכיתה ז, סטטיסטיקה: טבלת שכיחויות.
מנהלת המזנון צריכה לדעת כמה יש מכל מאכל.

- שלב 1 – סופרים על הדלפק: מעט מאכלים על מדפים; ממלאים שכיחות לכל מאכל; הסה״כ מחושב אוטומטית.
- שלב 2 – מחסן עמוס: הרבה מאכלים מפוזרים; אפשר לסמן כל מאכל שנספר.
- שלב 3 – תשובות מהסקר: תשובות כמותיות מגיעות אחת אחת ונעלמות; רושמים סימני ספירה בקבוצות של 5, ואז שכיחויות (הסה״כ מחושב אוטומטית).

כל הנכסים מוטמעים בתוך `index.html`: פונט Simpler Pro, לוגו, אייקונים וצלילים מתיקיית prisma, ואיורים מקוריים.

## פרסום ב־GitHub Pages
1. מעלים את `index.html` לשורש המאגר.
2. Settings → Pages → Branch: `main`, תיקייה `/ (root)` → Save.
